<h1 align="center">Brew Manager</h1>

<p align="center">
  用于安装与管理 <a href="https://brew.sh">Homebrew</a> 软件包的 macOS 原生图形界面客户端
</p>

<p align="center">
  <img src="docs/screenshot.png" width="800" alt="Brew Manager 截图">
</p>

## 主要特性

- **App Store 风格图形界面**: 网格卡片与列表视图自由切换，精选推荐与分类浏览
- **10 大智能分类**: 开发者工具、生产力、实用工具、设计、通讯、媒体、浏览器、安全、AI与数据及其他
- 自动检测 Homebrew 环境，支持一键自动化安装
- 汇集 8,500+ Formulae 与 7,700+ Casks，按真实安装热度排序浏览
- 支持关键词即时搜索
- 一键安装、卸载及全部更新

## 安装指南

### Homebrew
```bash
brew tap mrKangHo/tap
brew install brew-manager
```
